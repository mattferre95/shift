The FFmpeg build starts from [dfloresc/ffmpeg-macos-builds](https://github.com/dfloresc/ffmpeg-macos-builds) at commit `e95a80ee4eeaf8bdb4f208ccbc1952eb79e0b08a`, applies [`ffmpeg-lgpl-webp.patch`](../scripts/patches/ffmpeg-lgpl-webp.patch), and compiles checksum-pinned sources with `./build.sh lgpl arm64`. The patch adds BSD-licensed libwebp support, needed for SHIFT's still and animated WEBP exports. It does not enable GPL or nonfree components. H.264 export uses Apple's VideoToolbox encoder in place of x264. The FFmpeg executable reports `LGPL version 2.1 or later`; the package check rejects GPL flags and x264/x265 encoders.

## Distribution requirements

Every public binary release must carry the exact `SHIFT-ffmpeg-9.0.1-lgpl-corresponding-source.tar.xz` asset generated by [`scripts/build-ffmpeg-lgpl.sh`](../scripts/build-ffmpeg-lgpl.sh) alongside its DMG. That archive includes the seven pinned source tarballs, patched build scripts, patch file and build information. Keep the bundled license notices and shared FFmpeg libraries intact. They are placed in `Contents/Resources/ffmpeg-lib/` as separate shared libraries. Replacement under the final Developer ID signing model still needs validation before publication.

The LGPL path removes the earlier GPL-enabled FFmpeg build from the Apple Silicon release candidate, but it does not waive LGPL obligations. Verify that both the DMG and corresponding-source asset are published together. FFmpeg's [legal guidance](https://ffmpeg.org/legal.html) remains the primary checklist. A final Rust/JavaScript dependency notice inventory and Developer ID signing/notarization are release gates; the current local candidate is not a public release.
