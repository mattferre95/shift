# SHIFT — QA Checklist

Acceptance checks for V1. Automated coverage is named where it exists; the rest
is a manual pass on a real build.

## Automated

```bash
cd src-tauri && cargo test                                   # unit + pipeline
cargo test --test url_pipeline -- --ignored --nocapture      # needs network
```

- `cargo test --lib` — 17 tests: timestamp parsing and rejection, clip bounds,
  URL scheme rejection, filename sanitizing, collision-safe naming, remux vs
  transcode decisions, progress parsing.
- `tests/media_pipeline.rs` — 9 tests against generated media: probe, MP3/WAV
  extraction, MP4→MOV stream copy, **accurate trim (2.000→4.500 gives 2.5s
  ±0.15)**, VP9/Opus transcode, cancellation mid-encode, refusal to finalize an
  empty output.
- `tests/url_pipeline.rs` — 5 tests against live public sources: generic-extractor
  analysis, real-extractor analysis with backend thumbnail fetch, download +
  accurate clip to MP3, normalized failure on an unreadable link, cancelled
  download.

No copyrighted media is committed; fixtures are generated by FFmpeg or fetched
from published sample/CC-BY sources.

## Also verified

- Output folder is remembered between runs (`~/Library/Application Support/SHIFT/settings.json`).
- Per-job temp directories are removed on success and on cancel.
- No file is ever overwritten: `file.mp4` → `file-2.mp4` → `file-3.mp4`.
- Local media is never uploaded; only URL analysis and download touch the network.
- Thumbnails are fetched by the backend, never by the webview.

## Not yet covered

- Drag-and-drop from Finder (the code path is wired to Tauri's drag-drop event;
  only the file-picker path was exercised in the driven session).
- M4A / AAC audio-only inputs.
- Codesigning and notarization (see ARCHITECTURE.md).
- Behaviour when the destination volume fills mid-export.

## Regression watch

Two failures were expensive to find and would look like "the app just hangs":

1. **Any `pre_exec` on a spawned command** deadlocks the forked child in this
   Cocoa app. Use `process_group(0)`.
2. **A `<meta>` CSP in `index.html`** silently blocks every `invoke`. The CSP
   belongs only in `tauri.conf.json`.

If analysis or export ever hangs with no child process in `ps`, check these two
first.
